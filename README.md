# Апамдын туулган күнүнө куттуктоо сайтын орнотуу

Бүтүндөй сайт **бир жерде — Vercel'де** иштейт. `/` бети (`index.html`) куттуктоолорду көрсөтөт, `/form.html` форма куттуктоо кабыл алат, `/api/wishes` куттуктоону GitHub'дагы `wishes.json` файлына сактайт. GitHub токени серверде (Vercel Environment Variable) гана сакталат — HTML'ге эч качан жазылбайт.

## Биринчи жолу орнотуу

1. Репозиторийде `wishes.json` файлы бар экенин жана анын мазмуну `[]` экенин текшериңиз.
2. GitHub репозиторийин **public** кылыңыз. Бет куттуктоолорду резерв катары GitHub'дагы ачык файлдан окуй алат.
3. Ушул репозиторийди Vercel'ге импорттоп, deploy кылыңыз. `vercel.json` кереги жок — Vercel `api/` папкасын автоматтык түрдө сервер функциясына, ал эми `index.html` менен `form.html`'ди статикалык барактарга айлантат.
4. Vercel долбоорунда **Settings → Environment Variables** бөлүмүнө `GITHUB_TOKEN` кошуңуз. Анын мааниси — репозиторийдин `wishes.json` файлына **Contents: Read and write** укугу бар GitHub fine-grained token. Токенди HTML же GitHub'га эч качан жазбаңыз.
5. Vercel'де кайра deploy кылыңыз. Бардыгы бир доменде: башкы бет, форма жана API.

Каалаганда Environment Variables'ка `GITHUB_OWNER`, `GITHUB_REPO`, `GITHUB_BRANCH` менен башка репозиторийди көрсөтсөңүз болот. Демейки маанилер: `macbookali07-debug`, `apam-tuulgan-kunu`, `main`.

## Текшерүү

- Vercel'деги формага куттуктоо жөнөтүңүз. Ийгиликтүү болсо, форма башкы бетке (`/`) өтөт.
- GitHub'дагы `wishes.json` файлын караңыз: жаңы куттуктоо башына кошулушу керек.
- Башкы бетти жаңыртыңыз — куттуктоо тизмеде дароо чыгат (API кэшсиз иштейт).
- Сакталбаса, Vercel'дин **Deployments → Functions → `/api/wishes` → Logs** бөлүмүндөгү катаны караңыз. `GITHUB_TOKEN` коюлуп, туура репозиторийге жазуу уруксаты берилгенин текшериңиз.
