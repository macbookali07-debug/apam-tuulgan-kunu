# Локалдык көрүү

Бул сайтта куттуктоолор `localStorage`'га сакталбайт. `index.html` GitHub'дагы ачык `wishes.json` файлын окуйт, ал эми `form.html` куттуктоону Vercel'деги `/api/wishes` кызматына жөнөтөт. Ошондуктан HTML файлды түз ачканда (`file://`) форма жөнөтүлбөйт.

Толук иштетүү үчүн GitHub Pages жана Vercel'ге жарыялап, Vercel'де `GITHUB_TOKEN` Environment Variable орнотуңуз. Кадамдар `README.md` файлында.
